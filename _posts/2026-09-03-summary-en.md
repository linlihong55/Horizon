## [Biggest dark matter detector spots one weird particle event](https://www.science.org/content/article/world-s-biggest-dark-matter-detector-spots-single-weird-particle) ⭐️ 8.0/10

The LUX-ZEPLIN \(LZ\) experiment, the world&\#x27;s largest dark matter detector, has observed a single unusual particle event that could hint at physics beyond the Standard Model. Researchers caution that it is far too early to claim a discovery and are continuing to collect data. If the event is real, it could be the first sign of dark matter interactions or another new particle, which would shake up particle physics. Because LZ is the most sensitive experiment of its kind, even one unexplained event draws intense scrutiny from the field. The candidate event was registered deep underground at the Sanford Underground Research Facility, a former gold mine in South Dakota, where the detector sits 1,480 meters below the surface. The collaboration investigated possible mis-reconstructed events and backgrounds in its preprint, and LZ is now accruing data toward a total 1,000 live-day exposure.

hackernews · randycupertino · Sep 2, 13:40 · [Discussion](https://news.ycombinator.com/item?id=49536079)

**Background**: Dark matter is invisible material inferred from its gravitational effects, and it is thought to make up most of the mass of the universe. One leading explanation is weakly interacting massive particles, or WIMPs, which would rarely collide with ordinary atomic nuclei. Direct-detection experiments like LZ, formed by merging the LUX and ZEPLIN projects, use large volumes of liquid xenon deep underground to try to catch such collisions. A single candidate event is interesting, but more data are needed to raise it to the level of a discovery.

## [Paint.NET developer says Claude produced clean-room WINE Direct2D rewrite](https://simonwillison.net/2026/Sep/2/rick-brewster/) ⭐️ 8.0/10

Rick Brewster, the developer of Paint.NET, announced on the official forums that Paint.NET now ships an internal, from-scratch clean-room reverse-engineered rewrite of Direct2D for use under WINE, activated via a /wine flag. The implementation lives in PaintDotNet.Windows.Direct2D1.Managed.dll and was written almost entirely by Anthropic&\#x27;s Claude AI model. The rewrite could finally make Paint.NET usable in WINE on Linux, an outcome its developer said would never have happened without AI. More broadly, it is a high-profile example of an LLM producing a large, complex API implementation—and a candid admission that the resulting code cannot be meaningfully reviewed in practice. Brewster calls most of the code &\#x27;trust me bro&\#x27; style, saying it has not been thoroughly reviewed, and admits he cannot possibly review 180,000 lines. He had to routinely &\#x27;babysit&\#x27; Claude on resource management—early versions did not perform COM-style AddRef\(\) calls for reference-counted objects—but was impressed by Claude&\#x27;s reverse engineering of the formulas behind Direct2D&\#x27;s built-in effects library.

rss · Simon Willison · Sep 2, 05:50

**Background**: WINE \(Wine Is Not an Emulator\) is a compatibility layer that provides an implementation of the Win32 API so Windows applications can run on Linux, macOS, and other POSIX systems. Direct2D is a Windows API for hardware-accelerated 2D graphics, and Paint.NET depends on it heavily, which made WINE support difficult. Clean-room reverse engineering is a method of independently recreating a piece of software by studying its behavior and public specifications without copying its source code, often used to avoid copyright infringement.

Jasper Research published a detailed cookbook, an open-source codebase called nano-t2i, and the 100-million-image MONET dataset, enabling anyone to train a text-to-image model from scratch. The minimal training code can reproduce a flow-matching text-to-image model on a single H200 GPU for under $300. It will help practitioners, researchers, and learners bridge the gap between high-level papers and production-scale implementation. The MONET dataset is described as Massive, Open, Non-redundant and Enriched, and it ships with a retrieval interface for querying by text or image. nano-t2i is a minimal, hackable codebase released under Apache-2.0, while the cookbook itself is presented as an interactive technical report on Hugging Face Spaces.

reddit · r/MachineLearning · /u/dh7net · Sep 2, 14:40

**Background**: A text-to-image model generates an image from a natural-language description, and training one typically requires enormous compute, large curated datasets, and careful methodological decisions. This release packages those ingredients into an accessible deep-learning tutorial: a cookbook explaining the methodology, a tiny codebase for reproducible training, and a large open dataset. The project targets learners who want to understand the inner workings of modern text-to-image systems rather than simply use an API.
